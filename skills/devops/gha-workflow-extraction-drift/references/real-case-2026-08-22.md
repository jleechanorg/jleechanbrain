# Real case: worldarchitect.ai daily report, 2026-08-22

## What the user reported

> "report is now broken. not showing me top 20 users last week and last month"

The user pasted a Gmail email body that had section headers (`👥 Top 10 Users (Last Week):` and `👥 Top 10 Users (Last 4 Weeks):`) followed by **blank lines**.

## Diagnostic steps taken

1. Found the workflow file: `.github/workflows/daily-campaign-report.yml`.
2. Found the producer script: `scripts/daily_campaign_report.py`.
3. `git log --oneline -- scripts/daily_campaign_report.py` revealed PR #9250 (turn counting + entry timestamp filter) and PR #9269 (test alignment).
4. `git log --all --oneline -G "Top.*Users" -- scripts/daily_campaign_report.py` revealed PR #9248 — the actual culprit:
   - Commit message: `claudem/minimax-M3: feat(email-report): expand Top Users from top-10 to top-20 (#9248)`
   - It renamed the section header in `format_report()` from `"👥 Top 10 Users (Last Week):"` → `"👥 Top 20 Users (Last Week):"`.
5. `gh run view 32615606003 --log` (the 8/22 03:32 UTC run that produced the broken email) split into two streams:
   - **Generate Campaign Activity Report** step: full data, including `� TOTAL: 2,981 turns, $208.67` after `Top 20 Users (Last Week):`.
   - **Send Email Report** step: blank lines after `👥 Top 10 Users (Last Week):` because the workflow's sed regex `sed -n '/Top 10 Users (Last Week):/,/.../p'` matched zero rows.

## The fix (two-line sed update)

```diff
# .github/workflows/daily-campaign-report.yml
- TOP_WEEK=$(sed -n '/Top 10 Users (Last Week):/,/📅 LAST 4 WEEKS STATS/p' /tmp/report.txt | grep -E '^  [0-9]+ ' || true)
- TOP_4WEEKS=$(sed -n '/Top 10 Users (Last 4 Weeks):/,/DUPLICATE SCENE REPORT/p' /tmp/report.txt | grep -E '^  [0-9]+ ' || true)
+ TOP_WEEK=$(sed -n '/Top 20 Users (Last Week):/,/📅 LAST 4 WEEKS STATS/p' /tmp/report.txt | grep -E '^  [0-9]+ ' || true)
+ TOP_4WEEKS=$(sed -n '/Top 20 Users (Last 4 Weeks):/,/DUPLICATE SCENE REPORT/p' /tmp/report.txt | grep -E '^  [0-9]+ ' || true)
```

Also check `WEEK4_SECTION=$(sed -n '/LAST 4 WEEKS STATS/,/Top 10 Users/p' /tmp/report.txt)` on line 76 — same drift.

## Lesson

Workflow YAML extraction patterns are coupled to producer script labels but have no compile-time link. When you rename a label in the producer, grep the entire `.github/workflows/` for the old string BEFORE merging — same `## COMMIT: grep-before-constant-change` discipline as numeric constants.
