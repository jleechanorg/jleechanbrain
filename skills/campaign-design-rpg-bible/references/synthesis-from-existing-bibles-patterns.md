## Common Failure Modes When Synthesizing

1. **The synthesis becomes a clone of one source.** If the new design leans 70%+ on a single source bible, it's a new version, not a hybrid. Pull from 3+ sources per major mechanic.
2. **The hidden apex mechanic conflicts across sources.** Veleria uses Aether, Sylphina uses Divine Blessings, Nocticula uses Mana Veil. Don't stack; pick ONE hidden-apex mechanic for the hybrid.
3. **The 3-way deadlock becomes a 2-way or 4-way.** Three is the magic number — it forces single-faction double-dealing. Two (2) collapses to good-vs-evil. Four (4) makes the math too hard to track. Stay at 3.
4. **The mortal anchor is dropped.** Per User Preferences #3, default is to include the anchor. Only drop it if the user pushes back. Without an anchor, the MC becomes a power-fantasy without emotional stakes.
