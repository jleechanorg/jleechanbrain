# 2026-08-18 PR #9092 outage — Codex-quota cascade

## Symptom

PR #9092 (jleechanorg/worldarchitect.ai) was hung on the `/er` Evidence Gate. Agento's "what you can do right now" options presented MERGE APPROVED as the fastest path; the underlying cause was codex rate-limit (codex-code-review quota).

## Root cause

The chain-walking logic on the GHA side was missing. The daemon side (`daemon/src/er_runner.rs:230-253`) walks `skeptic_reviewer_priority()` on failure, but the runner side (`runner/dispatcher.py:91-180`) does NOT. Because codex rate-limit cascades into the GHA skeptic gate, the PR can't progress.

All stacked on `fix/jleechan-w0r4-reap-idle-worker-sessions` (not a clean branch from main). The fix was half-landed.

## Action taken

Dispatched a claudem worker on `feat/reviewer-fallback-on-quota` (clean branch from `origin/main`) to land the chain-walking in `runner/dispatcher.py` + 4 new tests.

## Lessons

1. **The dropped-thread followup fired** because the prior reply ended with "Say 'go' or correct scope" instead of driving the work. Per `finish-the-job` / `no-confirmation-gate`, when the goal is clear, drive to conclusion.
2. **The fix was already half-landed** — fixture plumbing existed but the callsite update was missing. Always check `git ls-files --others --exclude-standard` before assuming "no fix yet."
3. **Codex is NOT in the default priority queue** — so the user's instinct that "codex quota broke the factory" was correct in symptom but the underlying chain is `claudem → agy → cursor-agent`. Codex is still invoked when codex is explicitly listed (e.g., from worldarchitect.ai/AGENTS.md), but not as the default.
4. **The dropped-thread followup threshold is ~30 min**, not "until the user replies." The watcher picked up the silence even though the operator was away from the keyboard.

## Recovery transcript (operator message that unblocked)

Operator's instinct was correct — the default chain should self-heal. The dispatch was the durable fix; the immediate relief was `MERGE APPROVED` in the PR thread.
